# Netflix Project

This is a Netflix-inspired website that I built as a front-end project. I worked on the layout, styling, movie sections, navigation, and responsive design to make the website look and feel similar to a modern streaming platform.

I made this project mainly to improve my front-end development skills and get more comfortable with building a complete website from scratch.

## Features

* Netflix-inspired dark UI
* Responsive design
* Navigation bar
* Hero/banner section
* Movie and TV show sections
* Movie thumbnails and banners
* Interactive elements
* Responsive layout for different screen sizes

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Run

Clone the repository:

```bash
git clone https://github.com/Gouharhabib/Netflix-Project.git
```

Open the project folder and run `index.html` in your browser.

If you're using VS Code, you can also use the Live Server extension to run it locally.
